Rabaska OS
Le produit Droits

L’ordinateur d’occasion, enfin familier.

Rabaska OS est le système livré sur les machines reconditionnées. Interface claire, français d’abord, léger sur du matériel ancien. Ce n’est pas Windows, et ce n’est pas un Linux à télécharger.

Pas de téléchargement public

Rabaska OS n’est pas donné. Il est fourni avec l’ordinateur que vous achetez. L’image d’installation, les paquets et la recette de build ne sont pas publiés. Copier ou redistribuer le système n’est pas autorisé.

Pour qui

Des acheteurs non techniciens. Un bureau simple, des mots en clair, un bouton pour tout mettre à jour.

Sur quelle base

Une session Lubuntu / LXQt, habillée et outillée. Linux reste libre. La couche Rabaska, non.

Mises à jour

Les machines déjà livrées reçoivent le nouveau nom par le canal apt existant. Rien à réinstaller.
