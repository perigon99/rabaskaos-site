Technical sheet

What sits underneath, without rounding

Rabaska OS is not a kernel invented from scratch : it is a closed layer on a known Linux. Here is the real stack, as built.

Base

Lubuntu 26.04 image (Ubuntu family, 64-bit). LXQt desktop, Linux kernel, Calamares installer, SDDM login screen, Plymouth boot splash. Secure Boot kept.

Session

Default : LXQt on Wayland, labwc compositor (rounded top corners, 12 px). No drop shadows : blur costs too much on a small CPU. Fallback : LXQt on X11 with Openbox.

Rabaska layer

Cream and terracotta theme, Hanken Grotesk and Newsreader fonts. Start menu (search, four families, Shut down), day-one assistant, French update window, pinned LXQt bar.

Target hardware

Refurbished x86-64 PCs. Design target : little memory, a worn disk, a slow CPU (AMD C-50 class 1 GHz, 2 GB). At boot, a service tunes the disk scheduler and ZRAM. Not ARM, not Apple.

Video

YouTube in Chromium with hardware decode (VA-API) when the GPU allows. Spotify and many video services in the browser. Typical quality on this fleet : about 720p — not 4K.

Tablet

On a 360° convertible that reports tablet mode to the kernel, an on-screen keyboard (squeekboard) opens. On an ordinary laptop, nothing extra runs — no virtual keyboard “just in case”.

Network and software store

Ubuntu snap packages are removed : Firefox and Chromium come from .deb repos. A Linux software store (Discover) may be present ; it is not a phone app store.

Licences

Linux and base programs keep their original licences (often GPL). Theme fonts are OFL. Gemini belongs to Google. The Rabaska layer — look, menu, assistant, updates — is proprietary.

Limits

What Rabaska OS does not do

The main limit

This is not 4K.

Screen, graphics card, CPU : this is a used-PC fleet. Video runs around 720p. If you want a 4K workstation or recent games, this is not the right product — and we will say so.

This is not Windows Wine opens some .exe files ; many fail. Games and large professional apps, no.
No download No public ISO. The system arrives on the machine and may not be copied legally.
A closed look This is not a bare Ubuntu for an admin to tune. Theme and menu are fixed.
Depends on the seller channel Without that channel, the Rabaska layer stops evolving. The Linux base continues.
64-bit PCs only Intel or AMD. No phone, no ARM tablet, no Apple Silicon Mac.
Two invitations possible Lubuntu’s original notifier is still there : you may see two update notices until it is gone.
Under X11, square corners Without a compositor, the menu has square corners. That is intentional : better than blur that slows things down.

Buyer questions

The ten questions people ask us

Is this Windows ? No. It is a Linux system. The gestures are the same — click, double-click, a bar at the bottom, a menu — but names and look change.
My Word and Excel files ? LibreOffice opens, edits, and saves them. For a very complex document, layout may shift a little.
Can I watch Netflix ? Many video services are used in the browser. Quality and experience depend on the service and the machine — used-PC fleet, typically around 720p, not 4K.
And my old .exe programs ? A double-click tries to open them with Wine. Some work, many do not. Tell us which ones matter : we check before the sale.
Can I install other software ? Yes, from Linux repositories. It is the Rabaska look (theme, menu, assistant) that stays closed, not the machine.
How long do updates last ? The base gets Ubuntu-family security fixes. The Rabaska layer updates through our channel, for as long as we keep it.
Do I need an account for the assistant ? Yes : a Google account and a connection. The assistant opens Gemini in the browser. Without an account, the rest of the machine works the same.
Can I download it for my old PC ? No. There is no public image. Rabaska OS is delivered preinstalled on a machine we prepare.
What if the machine breaks ? Rabaska machines have a 3-month warranty. Write to us : we look with you before talking about repair.
Does it work on a Mac or tablet ? No. 64-bit Intel or AMD PCs only. On a convertible laptop, tablet mode is recognized.
